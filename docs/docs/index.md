# CDGS — Continuous Documentation Generation System

Welcome to the CDGS documentation.

> This documentation site is scaffolded in Phase 1 and will be populated as phases are implemented.

## What is CDGS?

CDGS connects to your GitHub repositories, listens for push events via webhooks, and automatically generates, versions, and publishes beautiful documentation powered by AI.

## Phases

| Phase | Status | Description |
|---|---|---|
| Phase 1 — Foundation | ✅ Complete | React frontend, Express backend, Supabase schema, Docker |
| Phase 2 — GitHub OAuth | 🔜 Planned | User auth, repo connection, webhook registration |
| Phase 3 — Queue & Jobs | 🔜 Planned | BullMQ worker, job processing, run management |
| Phase 4 — AI Generation | 🔜 Planned | OpenAI/Anthropic integration, doc generation |
| Phase 5 — Versioning | 🔜 Planned | Version diffing, publishing, rollback |
